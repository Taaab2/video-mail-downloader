# 📥 הורדות סרטונים דרך GitHub – עם תוסף דפדפן

שולחים קישור לסרטון, הסרטון יורד בענן של GitHub (עם עוגיות יוטיוב שלך כשצריך),
עולה כקובץ Release — וחוזר אליך **קישור הורדה ישיר**. הכול נשלט מתוסף Chrome:

* 🍪 **שולח את עוגיות יוטיוב** ל-Secret במאגר (בהצפנה, מהדפדפן עצמו)
* 🎚️ **בחירת איכות** לכל הורדה (עד 1080p, 720p, 480p, 360p או אודיו mp3)
* 🔑 **הטוקן מוטמע** בתוסף – אין צורך להקליד אותו בכל פעם
* 🚀 **הורדה בלחיצה** עם קישור ישיר בסיום, ורשימת ההורדות האחרונות
* ✉️ *(אופציונלי)* בקשות במייל: נושא עם המילה "הורדה" והקישור

המאגר: `https://github.com/Taaab2/video-mail-downloader`

## התקנת התוסף (פעם אחת)

1. פתחו `chrome://extensions` בדפדפן Chrome / Edge / Brave.
2. הפעילו **Developer mode** (מתג בפינה).
3. לחצו **Load unpacked** ובחרו את התיקייה `extension` שבתיקיית הפרויקט.
4. התוסף יופיע בסרגל. לחצו עליו לפתיחת לוח הבקרה.

הטוקן כבר מוטמע ב-`extension/lib/config.js` (הקובץ לא נכנס ל-Git), כך שאין מה להקליד.
אם תרצו לעבוד עם מאגר אחר – עמוד ההגדרות של התוסף מאפשר לעקוף את הטוקן והמאגר בלי לערוך קוד.

## שימוש

### הורדה בלחיצה
1. פתחו את התוסף ולחצו **"קח מהלשונית הפתוחה"** (או הדביקו קישור).
2. בחרו **איכות** ו**יעד העלאה** (GitHub / Drive / שניהם).
3. לחצו **הורד**. תוך מספר שניות ההרצה מתחילה, והחלון מציג התקדמות.
4. כשמסתיים — מופיע קישור ההורדה הישיר (עם כפתור "העתק").

### שליחת עוגיות יוטיוב (פעם בכמה שבועות)
לחצו **"שלח עוגיות ל-Secret"**. התוסף קורא את העוגיות של יוטיוב
(ו-google.com, אם צריך) ישירות מהדפדפן, ממיר אותן ל-`cookies.txt`, דוחס,
מצפין בקופסה אטומה (sealed box – אותו אלגוריתם של `libsodium`) ושולח אותן
כ-Secret במאגר. הן **לא נשמרות בתוסף** ולא נכתבות לקובץ במחשב.

נדרש רק לסרטונים שדורשים התחברות: סרטונים פרטיים, מוגבלי גיל או כאלה שדורשים
"אני לא רובוט". בלי עוגיות, סרטונים ציבוריים יורדים כרגיל.

> **חשוב:** כל עוד הסקרוט קיים, הריצה בענן נכנסת ליוטיוב בשמך. אם תבטלו את
> החיבור ("יציאה מכל המכשירים") — שלחו את העוגיות מחדש.

## שליחה במייל (אופציונלי)

אם בא לך גם לשלוח בקשות מהטלפון או מהמייל:

* **בנושא ההודעה** כתבו את המילה `הורדה` ואת הקישור, למשל:
  `הורדה https://www.youtube.com/watch?v=XXXX` (אפשר גם לשים את הקישור בגוף ההודעה).
* רק כתובת שברשימה הלבנה תטופל; כל השאר נזרק לתיקיית `Downloads-Failed`.
* ההרצה סורקת את התיבה כל 10 דקות, ומייל תשובה עם הקישור נשלח לשולח.

כדי שזה יעבוד צריך להגדיר במאגר שני סודות תחת
**Settings → Secrets and variables → Actions**:

| Secret | תוכן |
| --- | --- |
| `MAIL_USER` | כתובת המייל שלך |
| `MAIL_PASSWORD` | "סיסמת אפליקציה" בת 16 תווים (לא הסיסמה הרגילה!) |

בג'ימייל: הפעילו אימות דו-שלבי → [apppasswords](https://myaccount.google.com/apppasswords) →
וצרו סיסמת אפליקציה. בנוסף הפעילו IMAP בהגדרות Gmail.
אם המייל אינו Gmail, הוסיפו גם משתני סביבה (`IMAP_HOST`, `IMAP_PORT`, `SMTP_HOST`, `SMTP_PORT`).

## Google Drive (*אופציונלי*)

רוצים קישור של Drive במקום GitHub?

1. ב-Google Cloud צרו **Service Account** והפעילו **Drive API**.
2. הורידו מפתח **JSON** והדביקו אותו בהגדרות התוסף (או כ-Secret בשם `GOOGLE_SERVICE_ACCOUNT_JSON`).
3. ב-Drive שלכם צרו תיקייה, שתפו אותה עם כתובת המייל של חשבון השירות בהרשאת **עורך**,
   והדביקו את מזהה התיקייה כ-`DRIVE_FOLDER_ID` (משתנה, לא סוד).

חשוב: לחשבון שירות **אין אחסון משלו** – ההעלאה חייבת להיות לתיקייה ששותפה איתו באחסון שלך.
בחרו `drive` או `both` כיעד ההעלאה, ובהתאם להגדרות שהתוסף שולח בכל הרצה.

## הרצה ידנית מלשונית Actions

ב-GitHub → **Actions → הורדת סרטונים מהמייל → Run workflow** יש שדות:
`url` (קישור בודד), `quality`, `target`, `dry_run`, `max_messages`.

אותם שדות בדיוק עובדים גם משורת הפקודה:

```bash
python scripts/process_inbox.py --url "https://youtu.be/XXXX" --quality 720p --target github
python scripts/process_inbox.py --check          # בדיקת הגדרות, IMAP/SMTP, כלים ועוגיות
python scripts/process_inbox.py --dry-run        # סריקת תיבת הדואר בלי הורדה/העלאה/שליחה
python scripts/process_inbox.py --eml mail.eml   # בדיקת קובץ מייל שמור
python tests/test_parsing.py                     # בדיקות פענוח (48 בדיקות)
node extension/dev/tests.js                      # בדיקות התוסף (24 בדיקות)
```

## מגבלות שכדאי להכיר

* **המאגר חייב להיות ציבורי** כדי שקישורי ההורדה יעבדו. כל מי שיש לו קישור יכול להוריד —
  לכן אל תעלו לתוכו תוכן פרטי.
* **קובץ בודד עד 2GB** (המגבלה של GitHub Releases).
* **הטוקן מוטמע בתוסף** — הוא שמור בקובץ מקומי ולא במאגר. אם תשתפו את התוסף
  עם מישהו, או תפרסמו אותו, **בטלו את הטוקן** מיד וצרו חדש.
* **תזמון המייל נכבה** אחרי 60 יום בלי פעילות במאגר — כל דחיפה או הרצה ידנית מחזירות אותו.
* סרטונים דורשים לפעמים **עוגיות טריות**; אם הורדה מתחילה להיכשל, שלחו עוגיות מחדש.
* הורידו רק תוכן שיש לכם רשות להוריד.

## פתרון תקלות

| --- | --- |
| "הטוקן לא תקין" | הטוקן בוטל או שפג – צרו חדש והדביקו בהגדרות התוסף |

| עוגיות לא נשלחות | בדקו שאתם מחוברים ליוטיוב בדפדפן, ושיש הרשאת `cookies` לתוסף |

### הרשאות הטוקן הנדרשות

| הרשאה | בשביל מה |
| --- | --- |
| Contents: Read and write | לקרוא/לכתוב `config.json`, `whitelist.json` ולפרסם Releases |
| Actions: Read and write | להפעיל הרצות ולקרוא סטטוס ולוגים |
| Secrets: Read and write | לשלוח את עוגיות יוטיוב |
