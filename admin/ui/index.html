חיבור ל-GitHub

כדי שהמערכת תוכל לעדכן את הרשימה הלבנה, להפעיל הרצות ולקרוא תוצאות. יצירת טוקן: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token עם הרשאות Contents: Read and write, Actions: Read and write, Secrets: Read and write, Variables: Read and write.

מצב המערכת

    אבחון מקומי

    מריץ את אותה בדיקה שההרצה בענן מריצה: הגדרות, התחברות ל-IMAP/SMTP, yt-dlp ו-ffmpeg.

    העלאה ל-Google Drive (אופציונלי)
    
      
    
        אם תעדיפו קישור של Drive במקום או בנוסף ל-GitHub: צרו Service Account ב-Google Cloud,
        הפעילו את Drive API, הורידו מפתח JSON והדביקו אותו כאן. אחר כך שתפו תיקייה ב-Drive שלכם עם
        כתובת המייל של חשבון השירות (הרשאת עורך) והדביקו את מזהה התיקייה.
        בסוף בחרו "יעד העלאה" בהגדרות ההרצה למטה.
